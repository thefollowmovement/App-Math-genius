# Maquettes « Neon Stage »

Référence visuelle des écrans enfant, en HTML statique (390 × 844, iPhone).
Ouvre-les dans un navigateur depuis ce dossier pour voir les images des héros.

| Fichier | Écran de l'app |
|---|---|
| Main.html | Accueil enfant (`screens/child-home.tsx`) |
| Seance.html | Exercice en séance (`screens/practice/`) |
| Victoire.html | Fin de séance + coffre (`session-summary`, `chest-opening`) |
| Carte.html | Carte du monde (`screens/world-map/`) |
| Avatars.html | Choix du héros (onboarding / « Personnaliser ») |

Les maquettes montrent Nova ; dans l'app, c'est le héros choisi par l'enfant.
Couleurs, polices et personnages : voir `docs/design/personnages.md`.
