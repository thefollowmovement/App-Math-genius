# Compagnons (familiers)

Les compagnons accompagnent le héros de l'enfant. Ils peuvent :
- **encourager** après une erreur ou une bonne série ;
- **donner des indices** pendant un problème ;
- **évoluer** au fil des niveaux (plus tard : une image par stade d'évolution).
